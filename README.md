# CaseCraft

An interactive case investigation and evidence analysis platform.

## Tech Stack

- Frontend: React, JavaScript, HTML, CSS
- Backend: Java 21, Spring Boot
- Database: PostgreSQL

## Project Structure

- frontend/: React application
- backend/: Spring Boot REST API
- backend/src/main/resources/schema.sql: Database schema

## Running Locally

Run the frontend and backend separately. Refer to the configuration files and environment examples in their respective directories.
